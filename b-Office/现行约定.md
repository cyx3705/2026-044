## 公式库取舍

- **名字不走 History + 神名**：模块名、程序集名都是 `Norma`；页面 owner 仍按宿主规则推为 `HistoryNorma`。
- **一条公式一套元数据**：编号、名称、出处条款（GB/ISO/手册页码）、输入输出变量与单位、适用范围、依赖的查表。自描述就从这套元数据生成，不另写说明。✔
- **结构**：`b-Code/Norma/Formulas/` 是纯计算核心（`Calculation` 元数据 + 各类 `All()` + `Catalog`），**不许引用宿主**，将来原样抽成独立 NuGet 包；`NormaCommands` 把每条计算投成一条指令。✔
  - 加一条计算：在对应类的 `All()` 里加一个 `Calculation`；新一类就加一个静态类，再在 `Catalog` 里接上一行。
  - 测试会自动拿示例值跑一遍，但还是要在 `TestReferenceValues` 补一条手算或标准表的对照值。
- **单位全库统一**：长度 mm、力 N、扭矩与弯矩 N·m、应力与模量 MPa、功率 kW、转速 r/min、角度 °、寿命 h 或 10⁶ 转。例外要写在该量的元数据里（如过盈量 μm、公差 μm）。
- **系数的缺省值是粗估值**，例如 K_A 1.25、K_v 1.1。缺省值必须写进参数说明，让调用方知道是估的。查表才能得到的量（X/Y、材料极限、综合影响系数）一律由调用方输入，本库暂不带表。
- **判据只报结论，不拦结果**：不满足时指令照样成功，消息里列出哪条不成立；输入越界或缺参才算失败。
- **全部按公式自行实现**：0.2.0 没有拷贝任何第三方代码，齿轮也是按 ISO 6336 的公式自己写的。
- **0.2.0 的已知简化**：
  - 接触强度只算节点处，未计单对齿啮合系数 Z_B/Z_D；
  - 弯曲强度的 Y_F/Y_S 按方法 B 计算，但只验证了量级，以及齿数、变位对它们的影响方向，还没有对照过标准算例；
  - `fit.it` 给的是公式值，没有按标准规则圆整。
- **来源与许可（2026-11-03 调研）**：开源界和 NuGet 上没有能整体拿来用的机械设计公式库。
  - 齿轮：efirvida/python-gearbox（MIT，ISO 6336:2019 / AGMA 2001）可以移植，须保留署名。
  - pablomarcel/design 没有许可证，mechanical-kit 的数据是 CC BY-NC，二者只当核对样例，不拷代码或表格。
  - VDI 2230 螺栓和 ISO 281 修正寿命没有开源实现，只能按标准原文自己写。

## 工程约定

- **改动只进 dev 工作区。** 先 `vulcan.dev.start`，在 F 盘工作区里改，`submit` 送审热装，批准后 `finish`。直接改主树最后没法 finish。
- **只用统一契约（宿主 6.0.0 起编译期强制）。** 宿主给的只有一条总线和一个上下文：`ExecuteAsync` / `InvokeAsync` / `RequestConfirmation`，登记口只能 `Register`。数据目录、运行方式走 `context.Environment`，宿主位置问 `vulcan.host.info`。不引用 `HistoryVulcan.Services`，不拼 `%AppData%`。✔
- **版本三处一致**：`<模块>Version.props`、`module.manifest.json`、`project.manifest.json`。不一致时宿主静默跳过整个模块。✔
- **`ModuleInfo.ModuleName` 显式写死模块名**：缺省值是程序集名，同时也是指令域。✔
- **页面 owner = `History` + 首字母大写的指令域**，与模块名无关；对不上整页被 Aurora 静默拒收。✔
- **界面协议指令**（`<域>.ui.describe / actions / data`）只读并带 `HiddenReason`。✔
- **宿主程序集 `Private=false`**：部署时由宿主提供；测试工程反过来 `Private=true`。
- **`.gitattributes` 必须有 `z-Publish/** binary`**：否则快照换行，finish 热装 SHA 不符。✔
- **`.ps1` 必须带 UTF-8 BOM**；`SHA256SUMS` 与 manifest 不能带 BOM。✔
- **模块内不定义 `[ComImport]`**：可卸载装载上下文不能做 COM 互操作。✔
- **不读已移除的上下文成员**（`context.Settings` / `context.DataDirectory`）。宿主日志用 `context.Log`，过程用 `CommandContext.Progress`。✔
- **不跨仓 ProjectReference**，文档里也不写指向别的仓的相对链接。✔
- **外部程序的 API 以真机标定为准。** 文档与实测不符时，把证据写进本文件，用测试钉住实测组合。
- 手写 JSON 用编辑工具整文件写，不要经 shell heredoc（反斜杠会被吃掉）。
